# ExamPen Test Fixtures

Test data for development, unit tests, integration tests, and E2E tests.

Generated by `scripts/seed-data.sh` (see `scripts/README.md` for usage).

## Directory Structure

```
fixtures/
├── strokes/            # Binary stroke files (P05 pen coordinate frames)
├── pages/              # Sample rendered page images (PNG)
├── exams/              # Exam definitions with rubrics (JSON)
├── plagiarism/         # Known similar answer pairs (JSON)
├── ble/                # GATT characteristic dumps for pen simulator
├── students.json       # Student records
├── tutors.json         # Tutor records
├── ai_results.json     # AI recognition output samples
├── scores.json         # Score records (AI draft + overrides)
├── objections.json     # Objection lifecycle samples
├── chat_messages.json  # Sample teacher-student threads
└── seed.sql            # PostgreSQL seed script (idempotent)
```

## Fixture Types

### strokes/ — Binary Stroke Data

Binary files containing P05 pen coordinate frames. Each frame is 14 bytes:

| Field    | Bytes | Type   | Description                     |
|----------|-------|--------|---------------------------------|
| bookType | 1     | uint8  | Book type identifier            |
| bookSeq  | 1     | uint8  | Book sequence number            |
| pageNo   | 2     | uint16 | Page/question number            |
| coordX   | 2     | uint16 | X coordinate (pen units, 10/mm) |
| coordY   | 2     | uint16 | Y coordinate (pen units, 10/mm) |
| pressure | 2     | uint16 | Pen pressure (0=up, 1-1023)     |
| penProp  | 1     | uint8  | Pen property (0x00=down, 0x01=moving, 0x02=up) |
| padding  | 1     | uint8  | Reserved                        |
| timestamp| 2     | uint16 | Timestamp (16-bit, wrapping)    |

Format string (Python struct): `<BBHHHHBBH`

File naming: `pen_{student_id}_exam_{exam_id_prefix}_q{question}.bin`

### pages/ — Rendered Page Images

PNG images of rendered answer pages. Generated by `svc-doc-assembly` from stroke data. Used for AI pipeline testing and visual regression.

Currently placeholder — populated when `svc-doc-assembly` is built.

### exams/ — Exam Definitions

JSON files with exam configuration:
- Subject, class, duration, total marks
- Per-question rubrics with step-level mark breakdown
- Question region bounding boxes (pen-unit coordinates)
- Variant assignments (A/B/C/D)

### plagiarism/ — Known Similar Pairs

`known_pairs.json` contains pre-computed plagiarism detection pairs:
- TF-IDF cosine similarity scores
- Structural similarity (edit distance) scores
- Composite scores with threshold
- Used to validate `svc-plagiarism` detection accuracy

### ble/ — BLE Pen Simulator Data

GATT characteristic configuration for pen simulators (nRF52840-DK or software simulator):
- Service UUID and characteristic UUIDs
- Sample command/response hex sequences
- CRC-16/XMODEM polynomial and init values

### seed.sql — PostgreSQL Seed Script

Idempotent SQL script that:
1. Deletes existing seed records by ID (safe re-run)
2. Inserts students, tutors, exams, AI results, scores, objections, plagiarism flags, chat messages
3. Uses `ON CONFLICT (id) DO NOTHING` for safety

Load with: `psql $DATABASE_URL -f test-suite/fixtures/seed.sql`

## Regenerating Fixtures

```bash
# Default: 40 students, 3 exams, 10 questions each
./scripts/seed-data.sh

# Custom counts
./scripts/seed-data.sh --students 10 --exams 1 --questions-per-exam 5

# With different random seed (for variety)
./scripts/seed-data.sh --seed 123

# Load directly into database
./scripts/seed-data.sh --load-sql --db-url postgresql://user:pass@localhost:5432/exampen
```

Fixtures are deterministic: the same `--seed` value always produces identical output.
